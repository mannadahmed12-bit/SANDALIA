# SANDALIA - قالب متجر YouCan احترافي

## نبذة عن المشروع
قالب متجر إلكتروني احترافي لمتجر SANDALIA المتخصص في الأحذية والصنادل والبونطوفات برجالي ونسائي وأطفال.

### المميزات الرئيسية
✅ تصميم Premium وعصري بألوان الأسود والذهبي  
✅ Mobile First - متجاوب بالكامل  
✅ سرعة عالية وأداء محسّن  
✅ متوافق 100% مع نظام YouCan  
✅ SEO Friendly  
✅ دعم RTL/العربية  
✅ سهل الصيانة والتطوير  

## الهوية البصرية
- **اللون الأساسي**: الأسود (#000000)
- **اللون الثانوي**: الذهبي (#D4AF37)
- **خلفيات**: الأبيض (#FFFFFF)
- **تصميم**: Premium / Modern / Minimal

## هيكل المشروع
```
SANDALIA/
├── index.html              # الصفحة الرئيسية

├── checkout.html           # صفحة الدفع

│   ├── main.css           # الأنماط الرئيسية

```
